# 🧩 CCreator

**Генератор структуры файлов и папок по текстовому описанию** для Visual Studio Code.

![версия](https://img.shields.io/badge/version-1.1.1-blue)

---

## 📖 О расширении

Расширение позволяет быстро создавать иерархию папок и файлов по простой текстовой строке.  
Вы описываете структуру проекта, а утилита создаёт её прямо в вашей рабочей папке.

Подходит для:

- быстрого прототипирования,
- генерации шаблонов компонентов,
- создания структуры любого проекта (React, Vue, Svelte, Angular, Node.js и т.д.).

---

## 🚀 Возможности

- **Выбор целевой папки** – интерактивная навигация по существующим папкам с возможностью ввода имени новой папки.
- **Поддержка фреймворков** – Svelte, React, Vue, Angular.
- **Гибкая настройка компонента**:
  - выбор языка скриптов (`ts` / `js`),
  - выбор препроцессора стилей (`scss` / `less` / `css`),
  - для React — выбор типа компонента (`class` / `function`).
- **Генерация содержимого** – файлы создаются не пустыми, а с шаблонным кодом под выбранный фреймворк.
- **Гибкое описание структуры** – вложенные папки и файлы описываются в компактном текстовом формате.
- **Мгновенное создание** – все папки и файлы создаются рекурсивно за секунду.
- **Автообновление** – расширение проверяет наличие новых версий в GitHub-релизах. При обнаружении новой версии файл `.vsix` скачивается и открывается через встроенный API VSCode, после чего вам будет предложено установить обновление вручную (подтвердить установку).

## 🧭 Формат описания структуры

Строка состоит из **элементов**, разделённых двоеточием `:`.

- **Папка** заключается в угловые скобки `<...>`.
- Внутри папки сначала указывается **имя**, затем вертикальная черта `|`, затем содержимое (файлы и вложенные папки).
- **Файл** – просто имя, без специальных символов.
- Вложенность папок произвольная – вы можете создавать сколько угодно уровней.

### Примеры
1. Создаст папку `src` с двумя файлами: `index.js` и `style.css`.
   ```
   <src|index.js:style.css>
   ```
2. Создаст папку `components` с двумя Svelte-файлами и папку `utils` с файлом `helpers.js`.
   ```
   <components|Header.svelte:Footer.svelte>:<utils|helpers.js>
   ```
   Или просто укажите 
   ```
   <components|[Header,Footer].svelte>:<utils|helpers.js>
   ```
   И результат будет точно такой же

3. Создаст папку `project`, внутри неё – папку `src` с файлом `main.js` и папку `tests` с файлом `test.js`.
   ```
   <project|<src|main.js>:<tests|test.js>>
   ```

> 💡 Если вы не указали расширение файла, оно будет добавлено автоматически согласно выбранному фреймворку и настройкам.

## 🔧 Как использовать

1. **Откройте палитру команд** (`Ctrl+Shift+P` или `Cmd+Shift+P`).

### Далее на выбор несколько команд

#### Создать структуру файлов и папок для компоненты

2. Выполните команду:  
   `Создать структуру файлов и папок для компоненты`
3. **Выберите или создайте папку**, в которую будет помещена структура.
   - Если в текущей папке есть подпапки – они будут показаны для выбора.
   - Если подпапок нет – вам предложат ввести имя новой папки.
   - Можно просто нажать `Enter` без выбора – структура создастся в текущей папке.
4. **Выберите сохранённый пресет или один из последних своих**, ведь за счёт сохранения истории созданий можно не проходить весь путь до конца.
5. **Выберите фреймворк**: Svelte, React, Vue или Angular.
6. **Настройте компонент** в зависимости от фреймворка:
   - для Svelte/Vue: выберите язык скриптов (`ts` / `js`) и стили (`scss` / `less` / `css`);
   - для React: выберите тип компонента (`class` / `function`) и язык скриптов;
   - для Angular: дополнительные настройки не требуются.
7. **Введите строку описания** структуры (см. формат выше).
8. Нажмите `Enter` – структура будет создана с готовым шаблонным кодом!

#### Редактировать пользовательские шаблоны

2. Выполните команду:  
   `Редактировать пользовательские шаблоны`
3. **Выберите или создайте папку**, добавьте шаблон согласно инструкции:
   - Укажите имя шаблона
   - Укажить строку структуру, по которой создавать
   - Перечислите шаблоны для файлов, здесь можно гибко настроить по следующему принципу:
      * Если указать полное имя файла, например `Comp.svelte`, то для этого файла будет взято содержимое, указанное вами
      * Если указать расширение в формате `*.ts`, то все `.ts`-файлы будут с указанным вами содержимым, если не указано отдельно для файла (прошлый пункт)
      * Если не указать какие-то файлы из уже стандартных шаблонов, то будет взят стандартный
4. Нажмите `Сохранить всё в настройки VS Code` и теперь после выбора папки вы можете использовать пресет!

## 📦 Установка

### Через VSIX-файл (рекомендовано для команды)

1. Скачайте файл `*.vsix` из [раздела релизов](https://github.com/AvtoBBus/CCreator/releases).
2. В VSCode откройте панель расширений (`Ctrl+Shift+X`).
3. Нажмите на три точки (···) в правом верхнем углу → `Install from VSIX...`.
4. Выберите скачанный файл.

### Автообновление

Расширение автоматически проверяет наличие новых версий при каждом запуске VSCode. Если новая версия доступна:

1. `.vsix`-файл будет скачан во временную папку.
2. VSCode откроет этот файл с помощью встроенной команды `vscode.open`.
3. Вас попросят подтвердить установку расширения – нажмите **Install**.
4. После установки рекомендуется перезагрузить окно для применения обновления.

**Преимущество:** не требуется наличие команды `code` в `PATH`, всё делается через встроенные механизмы VSCode.

## 🛠 Разработка и сборка

Если вы хотите доработать расширение:

```bash
git clone https://github.com/AvtoBBus/CCreator.git
cd CCreator
npm install
npm run watch   # компиляция в режиме наблюдения
```

Для создания `.vsix`-пакета:

```bash
npm install -g @vscode/vsce
vsce package
```
